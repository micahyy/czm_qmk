# CZMAO Gamer

One-handed gaming keyboard series.
单手游戏键盘系列。

| Version | Keys | Encoder | USB VID:PID | Description |
|---------|------|---------|-------------|-------------|
| [v2](v2/) | 37 | Yes | 0x4E08:0x4E08 | Diode matrix, rotary encoder, RGB matrix |
| [lite](lite/) | 35 | No | 0x1A2C:0x50EF | Direct pin matrix, RGB matrix, throne compatible |

## Compilation / 编译

    make czmao/gamer/v2:via
    make czmao/gamer/lite:via

# mao_gamerst

35-key one-handed gaming keyboard with RGB matrix.

* Keyboard Maintainer: MAOKB
* Hardware Supported: STM32F103
* Hardware Availability: CZMAO

Make example for this keyboard:

    make czmao/gamerlite:default

Flashing example:

    make czmao/gamerlite:default:flash

## Bootloader

Enter the bootloader by holding the top-left key (ESC) while plugging in.
